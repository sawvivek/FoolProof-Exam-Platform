# Environment requirements

## Required for the demo
- Windows 10/11, macOS 12+, or modern Linux
- Node.js 22+
- npm 10+
- MySQL 8.0+
- 4 GB RAM minimum; 8 GB recommended
- Modern Chromium browser for the web portal
- Webcam for candidate readiness/camera demonstration

## Recommended for the secure desktop shell
- 8 GB+ RAM
- SSD
- One display for critical examinations
- Stable power at the examination centre

## Optional
- Python 3.11+ for future local AI services
- Docker Desktop for reproducible MySQL/Redis/MinIO deployment
- Android Studio for a future native companion (not used in this prototype)
