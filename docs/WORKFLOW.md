# End-to-end demo workflow

## Admin
1. Login.
2. View control center.
3. Review security policy.
4. Review people/roles and audit trail.

## Exam Conducting Body
1. Login.
2. Create/schedule critical exam.
3. Inspect exam registry and question set.
4. Enroll candidates (seeded for demo).
5. Hand off to candidate and proctor flows.
6. After candidate submission, evaluator can score and result can be published through API/UI extensions.

## Candidate
1. Login using one of 3 demo student accounts.
2. View assigned exam.
3. Review readiness checklist.
4. Start secure session.
5. Camera permission is requested for the primary camera only. No secondary mobile camera exists in this prototype.
6. Answer questions; per-question time and observational telemetry accumulate.
7. Simulate a network outage.
8. Continue working in offline-resilient state.
9. Restore network and synchronize.
10. Submit. Status becomes pending evaluation, not an immediate result.
11. After evaluation/publication, result PDF can be downloaded.
